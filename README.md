# Diego Carballo Andreo: Personal Site

A one-page portfolio in plain HTML and CSS. There's no build step and nothing to install.

## Preview locally

Open `index.html` in a browser.

## Before going live

These are placeholders in `index.html`:

1. **Social links:** replace each `your-handle` with your real profile URL. The links are LinkedIn, X, Instagram and GitHub. Delete any you don't use.
2. **Email:** replace `you@example.com` in the `mailto:` link.
3. **Projects:** replace the two "Project name" cards with your real projects. Each card has a title, a short description and a link. Copy an `<li>` block to add more, or remove the link if a project has none.
4. **Photo:** save your photo as `assets/avatar.jpg` (a square crop, at least 256×256). Then swap the `DC` placeholder `<div>` for the `<img>` tag shown in the comment just above it.

## Deploy with GitHub Pages

1. Merge into your default branch.
2. In the repo, go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select your default branch and the `/ (root)` folder.
4. The site will be live at `https://<username>.github.io/<repo>/` within a minute or two.

## Files

- `index.html`: all content
- `styles.css`: layout and colors. Light and dark themes are set by the variables at the top.
- `assets/favicon.svg`: the browser tab icon
